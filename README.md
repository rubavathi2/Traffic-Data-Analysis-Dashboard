# 🚦 Traffic Data Analysis Dashboard

## 📌 Project Overview

This project is an interactive Excel dashboard developed using 1000+ traffic records to analyze traffic patterns and identify useful insights.

The dashboard analyzes vehicle trends, peak hours, weather impact, and location-wise traffic. It also includes forecasting to predict future traffic patterns.

## 🎯 Objectives

- Analyze daily traffic trends
- Identify peak traffic hours
- Analyze traffic by vehicle type
- Understand the impact of weather on traffic
- Analyze traffic based on location
- Forecast future traffic patterns

## 🛠️ Tools & Techniques Used

- Microsoft Excel
- Pivot Tables
- Charts
- Slicers
- ETS Forecasting
- Data Analysis
- Data Visualization

## 📊 Key Dashboard Metrics

- Total Vehicles
- Peak Hour Traffic
- Average Daily Traffic
- Weekend Traffic

## 📈 Dashboard Analysis

The dashboard provides the following analysis:

- Traffic Trend – Day-wise
- Traffic by Vehicle Type
- Traffic by Weather Impact
- Traffic by Location
- Traffic pattern analysis
- Future traffic forecasting
